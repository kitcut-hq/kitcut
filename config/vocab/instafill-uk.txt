# Ukrainian-language vocabulary, fed to transcribe-words.py --hotwords-file.
# Companion to instafill.txt, which is the English list.
#
# Every entry is a term large-v3 actually got wrong on Ukrainian speech, with
# what it produced instead. Keep it that way: a hotword nudges the decoder on
# EVERY window, so padding this with ordinary Ukrainian makes the transcript
# worse, not better.
#
# NAMES DO NOT GO IN THIS FILE. People and clients are the highest-value
# hotwords there are -- a name is what a viewer checks, and Whisper reliably
# mangles one it has never seen -- but this file is shared with everyone who
# uses these scripts, and the names in your recordings are not theirs to have.
# Put them in a sibling `*.local.txt`, which .gitignore keeps out of the repo,
# and pass BOTH files; --hotwords-file is repeatable for exactly this reason:
#
#   python scripts/transcribe-words.py <film> --out <words.json> --language uk \
#       --hotwords-file config/vocab/instafill-uk.txt \
#       --hotwords-file config/vocab/names.local.txt
#
# One measured example of what that buys, with the name removed: a client's
# surname came back split across two words on every one of its appearances,
# and the correction cost a whole re-transcription because it was noticed
# afterwards rather than declared before.
